Printable cheat sheet

A one-page desk reference you can print (Ctrl+P / Print) and keep by your computer.

Before you paste — never share

  • ❌ IDs (SSN, driver’s license, passport, patient ID, account number)
  • ❌ Financial data (credit card, bank account, routing number, tax ID)
  • ❌ Credentials (passwords, API keys, secret tokens)
  • ❌ Private personal data (address, phone, birthday, diagnosis, medication)
  • ❌ Other people’s private data (client lists, patient charts)

✅ Replace real values with placeholders: [PATIENT], [ACCOUNT #], [AMOUNT], [EMAIL], [DATE]

Free AI tools

Cloud (free tiers): ChatGPT, Claude.ai, Google Gemini, Microsoft Copilot, Hugging Face Chat Local (offline, private): Ollama, LM Studio, AnythingLLM

Use local for anything sensitive. Use cloud for everyday articles.

Prompt templates

Article — TL;DR:

Summarize this article in one short paragraph. Main point and why it matters, plain English.

Meeting notes — decisions + actions:

Summarize these notes into: decisions made, action items (owner + due date), open questions.

Document — executive brief:

Summarize this document: purpose, key provisions, obligations, deadlines, risks. Max 300 words.

Email — thread summary:

Summarize this thread: what each person wants, decisions, action items, deadlines. Under 100 words.

Length & tone controls

Add to any prompt:

Want Add this
Short “Under 100 words” / “one paragraph”
Bullets “Use bullet points”
Professional “Professional tone”
Simple “Plain English, no jargon”
Friendly “Friendly, casual tone”

Remember

  • AI can invent facts — check names, dates, and numbers
  • This handbook is education only, never medical or legal advice
  • Sanitize before you paste
