# Length & tone controls

A great summary matches the audience. These controls let you tune any summary to the right size and voice.

## Length controls

Add one phrase to your prompt:

| Length | Phrase to add |
|---|---|
| Ultra short | “One sentence” / “one line” |
| Short | “Under 100 words” / “one short paragraph” |
| Medium | “3–5 bullet points” / “about 200 words” |
| Long / thorough | “Be detailed” / “include key supporting facts” |

**Example:**
```
Summarize this article in exactly 3 bullet points, under 80 words each.

[TEXT]
```

## Tone controls

| Tone | Phrase to add |
|---|---|
| Professional / executive | “Professional tone, executive style” |
| Friendly / casual | “Friendly, casual tone” |
| Simple | “Plain English, no jargon” / “explain like I’m new to this” |
| Direct / action-oriented | “Direct, action-focused tone” |

## Mixing length + tone

You can combine them in one prompt:

```
Summarize this meeting into 4 bullets, friendly tone, plain English. Include decisions and action items with owners. Under 120 words total.

[MEETING NOTES]
```

## Cheat sheet of control phrases

Copy these into any prompt:

- “Keep it short.”
- “Use bullet points.”
- “No jargon, plain English.”
- “Professional tone.”
- “Under 100 words.”
- “One paragraph.”
- “Explain like I’m 12.”
